# Study Buddy Pro

create me an app for students:
I want to be able to create a stuctured docx file, taking a file/pdf as an input. Which can be dragged or uploaded from the UI,  

and the generated document will have
-questions from the pdf
-Solutions for each questions just below the questions

the application should provide a downlaodable file/pdf based on what the user selects from the option.

The motive of the application is that when a student uplaods a file which contains questions/mcqs without solutions they are given a proper stuctured document as a output with solutions with explanation of those questions without them having to crawl through the internet searching the answers. ease of learning.

Create me an MVP/prototype using demo data, I aim to use an llm api for this, but for now create me the prototype using dummy data. 

feel free to get creative for the features of the application. let user have options to custom the generated document before they hit "generate", once the source file is uploaded.
